PROJECT: PHẦN MỀM QUẢN LÝ THU CHI CÁ NHÂN

Giới thiệu cấu trúc chương trình:
Tên đề tài: Phần mềm Quản lý thu chi cá nhân.
Ngôn ngữ lập trình: Java.
Công cụ phát triển: Android Studio.
Cơ sở dữ liệu: SQLite.
Giao diện: XML.

Các chức năng của app: 
Thêm giao dịch.
Hiển thị danh sách giao dịch.
Tìm kiếm và lọc giao dịch.
Sửa giao dịch.
Xóa giao dịch.
Thống kê thu chi theo tháng/năm.
Thoát ứng dụng.
